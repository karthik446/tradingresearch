### w1l4.1 write the variant prompt

**Concept.** A prompt is a file in git, so an arm names exact text. The variant changes only the rules, and each new rule answers a taxonomy row: if the role or the format also moved, a difference could not be traced. [Prompt version](concepts.md#prompt-version), [failure taxonomy](concepts.md#failure-taxonomy).

**The four target classes** are the four class ids [lab w1l2 fixes](w1l2.md#lab-w1l2-open-and-axial-coding), the mechanical ones a rule in the prompt can address: `window_name` (31 claims), `inference_wider` (15 analyses), `opinion_cites` (5) and `label_in_value` (4). Add one rule for each. `judgement_in_fact` is larger but waits for a judge (ADR-001).

**You edit** `prompts/analyze-2.txt`. The stub is a copy of `analyze-1.txt`; the rules block is where you work:

```text

- Write numbers ONLY in "value". In "text", refer to it as {value}. Name indicators by their table name
  (sma_200, high_20, rsi_14). Dates as YYYY-MM-DD are allowed.
```

### w1l4.4 cluster bootstrap

**Concept.** A ticker's two days move together, so there are 10 independent draws, not 20. Resample whole tickers, take the mean diff each time, and read the interval off the 2.5th and 97.5th percentiles. Below 10 clusters the interval means little, and `compare` refuses. [Cluster bootstrap](concepts.md#cluster-bootstrap), [confidence interval](concepts.md#confidence-interval).

**Which percentile.** There are several conventions for reading a percentile off n sorted values; this lab uses the plain index one, no interpolation. Sort the n means; the low end is the mean at 0-based position `int(n * (1 - level) / 2)` and the high end the one at `int(n * (1 + level) / 2) - 1`. For n = 10000 and level 0.95 that is positions 250 and 9749. The tests allow ±0.02 around compare's interval, so a neighbouring convention also passes; this one is what the solution uses.
