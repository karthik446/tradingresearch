# Hints: w1l4.3

## Hint 1

Pairing means one difference per item, so check that both sides have the same items first. For a 0/1 metric a
difference is +1, 0 or -1; McNemar uses only the +1s and -1s.

## Hint 2

Under "no difference", each discordant pair is a fair coin. The two-sided p is twice the probability of a count
at most as extreme as the smaller of the two, capped at 1. (14, 0) gives 2 / 16384 = 0.000122.
