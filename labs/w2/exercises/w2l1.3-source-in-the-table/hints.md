# Hints: w2l1.3

## Hint 1

What does "in the table" mean for a source id: that the table has a row for it, or that the row holds a number? A
label row holds None and is still a row. So a fact citing that label is fine here, and a fact citing an id the
table never had is not.

## Hint 2

Which claims does rule 3 judge at all? An inference rests on its parent claims, not on table rows; ask what this
check should say about one before it reads its sources. Then picture a fact citing three sources whose third is
missing from the table: does it still trace to the table? Make sure your answer looks at the third.
