### w2l1.4 the number matches a source

**Concept.** Rule 4: a fact's number must be one code computed, so it has to match at least one of its cited sources within the 0.5% relative tolerance (`close_within`, already in the file, edge included). A fact without a value (a label) passes; a source holding None has no number to match. 0.0 is a number. [Tolerance](concepts.md#tolerance).

**You edit** `evidence_ok` ([stub](../exercises/w2l1.4-number-matches-a-source/stub/src/tradingresearch/checks.py)):

    if any(source not in values for source in claim.source_ids):
