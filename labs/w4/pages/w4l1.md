### w4l1.1 closed schemas

**Concept.** The model knows a tool only by its name, its description and its argument schema. The stub's schemas are `{"type": "object"}`: they list no argument and allow any, so the model is not shown what to send, and whatever it sends passes. The recorded model sent `{"groups": [...]}` to the capture's own tool; an open `get_indicators` would take the same, ignore it and answer as if asked for nothing. A closed schema lists exactly the arguments its handler reads, each typed and described, and sets `"additionalProperties": false`. [Closed schema](concepts.md#closed-schema).

**You edit** the `parameters` of each tool in `TOOLS` ([stub](../exercises/w4l1.1-closed-schemas/stub/src/tradingresearch/tools.py)):

```python
#   lists) whose properties are exactly the arguments its handler below reads, each typed and described, so the model
#   is shown what it may send and nothing else.
TOOLS: tuple[ToolSpec, ...] = (
    ToolSpec(
        name="get_indicators",
        description=(...),
```

### w4l1.2 errors the model reads

**Concept.** The loop passes back to the model only the text `run_tool` returns. The stub looks the handler up and parses the arguments with no guard, so the recorded call to `get_sources`, a tool that is not offered, raises `KeyError` and ends the turn in a crash the model never sees. Every mistake in a call has to come back as `{"error": "..."}`: one key, a sentence saying what was wrong and how to call again. An empty argument text is not a mistake: it means no arguments. [Tool error](concepts.md#tool-error).

**You edit** `run_tool` ([stub](../exercises/w4l1.2-errors-the-model-reads/stub/src/tradingresearch/tools.py)):

```python
def run_tool(ctx: Context, name: str, arguments: str) -> str:
    """One tool call on `ctx` as JSON text; every mistake in the call is an {"error": ...} result, never raised."""
    # TODO(w4l1.2) every mistake in a call comes back as {"error": "<what was wrong, how to call again>"}, never
    #   raised: a name that is not a tool (the message names every tool), argument text that is not a JSON object (an
    #   empty text is no arguments), an argument the tool's schema does not list, a value that is not a non-empty list
    #   of strings, and the ToolError a handler raises.
    rows = HANDLERS[name](ctx, json.loads(arguments))
    return json.dumps({"rows": [_shown(row) for row in rows]})
```

- `run_tool(..., ...) returned {...}: an error is an object with one key, "error", holding a non-empty sentence`
- `the error for the recorded call to 'get_sources' is '...'; it does not name get_indicators, .... The model called a tool it was never offered; it can only call a real one next if the error lists them all`

- `with the arguments '' the three tools return N rows between them; the FAKEA context has 38, and none of them returns ...: each handler picks its share of the context, and a call with no arguments answers all of it, each row once. A row left out is a number the model can never cite` (or rows that come back more than once)
- `run_tool('get_indicators', '{"names": ["close"]}') returned {"error": ...}: the schema allows that call and the handler serves it, so it is answered with rows. A check that refuses every argument turns each good question into an error the model cannot fix`

```diff
+def _lookup(name: str) -> tuple[ToolSpec, Callable[[Context, dict], list[Row]]]:
+    spec = next((s for s in TOOLS if s.name == name), None)
+    if spec is None:
+        raise ToolError(f"unknown tool {name!r}; the tools are {', '.join(NAMES)}")
+    return spec, HANDLERS[name]
+
+
+def _arguments(spec: ToolSpec, raw: str) -> dict:
+    """The model's raw argument text checked against the tool's closed schema (every property is a string list)."""
+    try:
+        args = json.loads(raw) if raw.strip() else {}
+    except json.JSONDecodeError as exc:
+        raise ToolError(f"{spec.name}: arguments are not valid JSON ({exc.msg}); send a JSON object") from None
+    if not isinstance(args, dict):
+        raise ToolError(f"{spec.name}: arguments must be a JSON object, got {type(args).__name__}")
+    properties = spec.parameters["properties"]
+    unknown = sorted(set(args) - set(properties))
+    if unknown:
+        allowed = ", ".join(properties) or "none"
+        raise ToolError(f"{spec.name}: unknown argument(s) {', '.join(unknown)}; allowed: {allowed}")
+    for key, value in args.items():
+        if not isinstance(value, list) or not value or not all(isinstance(v, str) for v in value):
+            raise ToolError(f"{spec.name}: {key} must be a non-empty list of strings, got {json.dumps(value)}")
+    return args
```

### w4l1.3 the rows it cites

**Concept.** A claim cites a row by its `source_id`, and the claim check rejects a `source_id` it does not know. The stub's rows are `{"name": ..., "value": ...}`: nothing to cite, no unit, and the value as computed, so on the extra-digits copy the model reads a close of 101.40124722 where the fixed SOURCES table shows 101.401, and the two modes no longer answer from the same numbers. A row is `{source_id, name, unit, value}`, plus `label` for the market regime, its value written as the table writes it. And `names` has to filter: the stub returns all 21 rows whatever is asked.
