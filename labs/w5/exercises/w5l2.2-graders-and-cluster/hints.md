# Hints: w5l2.2

## Hint 1

Ask what the result will be read with. The rule you write next needs a primary metric and a guard; the whole-analysis
score is reported beside them; and each section you could drop needs its own grader, so you can see which part of the
context the bad claims came from. Nothing else: a grader that calls a model cannot be trusted on an arm that hid rows
from it, and the run refuses one there before its first call.

## Hint 2

Seven names, each once, and every one a grader the registry calls code. The per-claim rate and the all-or-nothing
score are different graders with similar names; the inference chain has a grader of its own that this question does
not need. The cluster is a top-level key like the tickers, not part of an arm, and it is written out even though the
loader would pick the same unit by itself, so whoever reads the file sees how the intervals are built.
