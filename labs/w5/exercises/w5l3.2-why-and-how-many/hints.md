## Hint 1

A skipped line has to let the reader tell the two cases apart: an arm that never scored the grader at all (the drop
arm's own section) and two arms that scored it on different ticker-days. The counts are what each run scored on its
own, not what they share, so the levels line in the chapter reads 1 against 3 although they share none.

## Hint 2

Check the empty case before the common-item case: a run with no score also shares no item, so the other order labels
it wrong. Build each entry as you skip the grader, so the entries keep the order asked; the refusal joins the same
entries with a semicolon and a space, and has a fixed text for the case where nothing was asked.
