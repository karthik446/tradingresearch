**What you build:** `SectionGrounded` in `src/tradingresearch/evals.py` and its four registered graders, `indicators_grounded`, `levels_grounded`, `edgar_grounded` and `headlines_grounded`. ### w5l1.2 not cited, not parsed

**Concept.** [Not cited](concepts.md#not-cited): a section no claim cites raises `CannotGrade("not_cited: ...")`, so it gets no score, never 1.0; a mean that counted silence as success would pass every section the model ignored. A reply that did not parse [cannot be graded](concepts.md#cannot-grade) at all, whatever it holds. Below 1.0 the explanation names the failed claims' reasons and how many of the citing claims fail.

### w5l1.3 four graders and the drop

**Concept.** A [drop arm](concepts.md#drop-arm) never shows the model some sections of the context. A claim that cites a row the arm never saw cannot be grounded in what the model was shown, so the validator rejects it (`dropped_source`), and the grader needs the arm's `drop` to tell the validator which rows were hidden. One registered code grader per section of `masking.SECTIONS`, id `<section>_grounded`, makes the four scores available to any config by name.
