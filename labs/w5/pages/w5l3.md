### w5l3.1 the graders both arms scored

**Concept.** A [skipped grader](concepts.md#skipped-grader) is one of the graders asked that two runs cannot be compared on: one run never scored it, or the two runs scored it on no common item. Core `compare` refuses the whole comparison over such a grader (`metric_missing`, `no_paired_items`), so `experiment.compare` leaves it out, compares the rest and names it in `Compared.skipped`. One common item is enough to keep a grader. With [no shared metric](concepts.md#no-shared-metric) left, it refuses as core refuses.

**You edit** `experiment.compare` ([stub](../exercises/w5l3.1-the-graders-both-arms-scored/stub/src/tradingresearch/experiment.py)). <details>
<summary>Solution (after green)</summary>

```diff
-    raise NotImplementedError
+    kept: list[str] = []
+    skipped: list[str] = []
+    for grader in graders:
+        values_a, values_b = a.values(grader), b.values(grader)
+        if not values_a or not values_b:
+            skipped.append(f"{grader}: not scored in both arms")
+        elif not values_a.keys() & values_b.keys():
+            skipped.append(f"{grader}: no item scored in both arms")
+        else:
+            kept.append(grader)
+    if not kept:
+        raise ComparisonRefused("no_shared_metric", "no grader is scored on a common item in both runs")
+    return Compared(core_compare(a, b, kept), tuple(skipped))
```

### w5l3.2 why and how many

**Concept.** A [skipped grader](concepts.md#skipped-grader) line is only useful if it says which of the two cases it is and how big each side was: `not scored in both arms (n=6 vs 0)` says the drop removed the section, `no item scored in both arms (n=1 vs 3)` says both arms scored it, on different ticker-days. The [no shared metric](concepts.md#no-shared-metric) refusal names every grader it left out, so a reader never has to guess why nothing was compared.
