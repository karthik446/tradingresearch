### w3l1.2 unknown is an abstain

**Concept.** The rubric lets the judge say `unknown` when the summary does not show whether a mechanism happened. ADR-003 keeps the verdict binary: gigai-core's `JudgeVerdict` is pass or fail, and journal.py's `judge_verdict` table has `CHECK (verdict IN ('pass', 'fail'))`. So an unknown is stored as `fail` with a reason that starts `unknown: `. `journal.abstained` reads exactly that prefix, and `tr label agree` leaves those trades out of kappa instead of counting them as not met. [Abstain](concepts.md#abstain).

**You edit** `p1_verdict` ([stub](../exercises/w3l1.2-unknown-is-an-abstain/stub/src/tradingresearch/evals.py)):

```python
    verdict = last_json_object(reply, "verdict")
    # TODO(w3l1.3) a reply with no pass, fail or unknown verdict cannot be graded: raise CannotGrade, quoting the reply.
    explanation = last_json_object(reply, "explanation")
    reason = explanation if isinstance(explanation, str) else ""
    # TODO(w3l1.2) a verdict of unknown is an abstain: fail, with "unknown: " before its explanation (ADR-003).
    return verdict, reason
```

### w3l1.3 no verdict cannot be graded

**Concept.** An abstain is the judge's answer that it cannot decide. A reply with no readable verdict is not an answer: no JSON, a last object with no `verdict`, `maybe`, `Pass`, `null`, or a reply cut off by `max_tokens` inside its object. Storing it as a fail or an abstain would count a reply nobody can read. `p1_verdict` raises gigai-core's `CannotGrade`, quoting the reply: nothing is stored, the trade stays unjudged, and the call's cost is still in its run file. [CannotGrade](concepts.md#cannotgrade).

**You edit** `p1_verdict` ([stub](../exercises/w3l1.3-no-verdict-cannot-be-graded/stub/src/tradingresearch/evals.py)):

```python
    verdict = last_json_object(reply, "verdict")
    # TODO(w3l1.3) a reply with no pass, fail or unknown verdict cannot be graded: raise CannotGrade, quoting the reply.
    explanation = last_json_object(reply, "explanation")
    reason = explanation if isinstance(explanation, str) else ""
    if verdict == "unknown":
        return "fail", reason if reason.startswith("unknown:") else f"unknown: {reason}"
    return verdict, reason
```
